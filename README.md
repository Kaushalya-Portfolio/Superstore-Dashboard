# Superstore-Dashboard
A Power BI dashboard analyzing sales, profit, and quantity for a retail superstore, with insights by region, segment, category, and discount level.
Key Metrics:
Sum of Profit: 60.30K
Sum of Sales: 429.65K
Sum of Quantity: 7K

Features
Filters: Region (Central, East, South, West), Segment (Consumer, Corporate, Home Office), and Ship Mode (First Class, Same Day, Second Class)
Sales & Profit by Segment: Donut chart breakdown of performance across customer segments
Profit by State: Horizontal bar chart highlighting top-performing states
Profit by Category: Comparison across Technology, Office Supplies, and Furniture
Profit by Sub-Category: Detailed donut breakdown (Copiers, Phones, Accessories, etc.)
Sales by Discount: Funnel view showing how discount levels affect total sales

Tools Used
Power BI Desktop for dashboard creation
Data modeling and DAX for calculated metrics
